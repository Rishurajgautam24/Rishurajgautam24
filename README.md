## Featured Data Science Projects

### 1) Data Scientist Salary Analysis (EDA)
**Repository:** https://github.com/Rishurajgautam24/Data_Scientist_Salary_Analysis
- **Problem:** Understand which factors are associated with salary variation in data roles.
- **Approach:** Data cleaning + exploratory analysis focused on distributions, group comparisons, and interpretability.
- **Methodology:** descriptive statistics, aggregation, comparative plots, and structured EDA workflow.
- **Results / impact:** analyzed **3,755 records × 11 variables** to surface patterns across experience level, job title, and employment type.
- **Tech stack:** Python, Jupyter Notebook.
- **Artifacts:**
  - Notebook: https://github.com/Rishurajgautam24/Data_Scientist_Salary_Analysis/blob/main/Data%20Science%20Salaries%20Analysis.ipynb

### 2) EDA on Terrorism Dataset
**Repository:** https://github.com/Rishurajgautam24/EDA-on-Terrorism-Dataset
- **Problem:** Identify terrorism “hot zones” and summarize incident patterns for security/defense analysis.
- **Approach:** EDA to rank and compare regions by incident characteristics and impact.
- **Methodology:** cleaning, grouping, frequency analysis, and visualization-driven storytelling.
- **Results / impact:** produced an investigation-ready notebook to highlight high-risk regions and key incident trends.
- **Tech stack:** Python, Jupyter Notebook.
- **Artifacts:**
  - Notebook: https://github.com/Rishurajgautam24/EDA-on-Terrorism-Dataset/blob/main/Terrorism%20EDA.ipynb

### 3) Movie Recommendation System (Content-Based)
**Repository:** https://github.com/Rishurajgautam24/Movie_recommender_system
- **Problem:** Recommend similar movies given a user’s input title.
- **Approach:** Convert movie metadata into vectors and retrieve nearest neighbors using similarity scoring.
- **Methodology:** Bag-of-Words via `CountVectorizer`, cosine similarity, top‑k ranking.
- **Results / impact:** generated top‑5 recommendations over **10,000 movies** using an interpretable similarity pipeline.
- **Tech stack:** Python, Pandas, scikit-learn.
- **Artifacts:**
  - Notebook: https://github.com/Rishurajgautam24/Movie_recommender_system/blob/main/Movie%20recommendation.ipynb
  - App entrypoint: https://github.com/Rishurajgautam24/Movie_recommender_system/blob/main/app.py

### 4) Iris Flower Classification (Decision Tree & Random Forest + GUI)
**Repository:** https://github.com/Rishurajgautam24/IRIS_FLOWER_CLASSIFICATION_WITH_GUI
- **Problem:** Classify iris species from four measured features.
- **Approach:** Train baseline models, validate accuracy, then expose inference through a simple UI.
- **Methodology:** Decision Tree + Random Forest classification; evaluation via accuracy.
- **Results / impact:** Random Forest achieved **96.67% accuracy** (Decision Tree reached **100%** but overfit).
- **Tech stack:** Python, scikit-learn, Streamlit.
- **Artifacts:**
  - Notebook: https://github.com/Rishurajgautam24/IRIS_FLOWER_CLASSIFICATION_WITH_GUI/blob/main/Iris%20Flowers%20Classification%20ML%20Project.ipynb
  - App: https://github.com/Rishurajgautam24/IRIS_FLOWER_CLASSIFICATION_WITH_GUI/blob/main/app.py
